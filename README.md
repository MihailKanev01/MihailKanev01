## Selected Projects

### [Fuel Tracker Bulgaria](https://github.com/MihailKanev01/fuel-tracker-bulgaria)
Production-oriented price-tracking architecture using Next.js, TypeScript, PostgreSQL and Prisma, with validation, audit-oriented observations and a protected collection API.

### [Ben 10: Project](https://github.com/MihailKanev01/Ben-10-Project)
Unity/C# 3D action-adventure prototype featuring transformation flow, multiple alien forms, gameplay abilities, UI and third-person camera systems.

### [NarutoGame](https://github.com/MihailKanev01/NarutoGame)
Unity 6 third-person prototype focused on camera-relative movement, smooth player rotation, animation state updates and mouse-controlled camera follow.

### [Traffic Management](https://github.com/MihailKanev01/tu-varna-csharp-winforms-traffic)
C# Windows Forms application demonstrating multi-form navigation, transport-line and stop selection, map navigation and event-driven UI logic.

### [Endless Runner](https://github.com/MihailKanev01/Endless-Runner)
Unity/C# gameplay prototype with forward movement, jumping, procedural ground tiles, obstacles, collectibles, scoring and increasing speed.
